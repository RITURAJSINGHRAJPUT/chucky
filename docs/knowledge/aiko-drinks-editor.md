**Aiko Drinks editor** (2026-07-05) — 4th editor in Chucky, live at `/drinks/`, tile added to the `/chucky/` picker (lime accent #A8D93A, "Drinks · Aiko · Mocktails & sodas"). Source PDF: `~/Downloads/Aiko Drinks Menu (3).pdf` (v3 — 360 prices + MANGO CHAMOY/IYOSHI COLA; the older screenshot showed 300s). Also `~/Downloads/Aiko Drinks Menu.ai`.

**Structure:** 9.9×21cm, 2 pages. Page 0 = gradient cover (DRINKS MENU, not editable). Page 1 (menu) = ~11 drinks on **fixed colored gradient bands** (`/ShN sh` shadings): 8 SIGNATURE mocktails (name + desc + price) + 3 SOFT DRINKS (name + price, no desc, bottom block via Td chain). Text is kerned `[...]TJ` (name size 9, desc/price size 7); price positioned by `Td` relative to the desc's LINE start (not its text) so editing text never shifts the price. Same font family as Aiko food menu but page-1 `/TT0` = **MonospaceTypewriter** (not Geist).

**Build/engine:** `src/drinks/build_drinks_map.py` parses page 1 → fieldmap.json (fields name/desc/price with `[...]TJ` byte spans + x/y, items grouped & ordered by y desc) + saves `drinks.pdf` UNCOMPRESSED (`stream_decode_level=generalized`). Engine = a MINIMAL byte-splice editor (reuses spliceBytes/regenerate/renderPreview/boot verbatim from churnd): edit = replace field span with `[(NEW)]TJ` (collapses kerning, fine). Shell = the redesigned shell (rail Menu/Cover tabs + SIGNATURE/SOFT DRINKS sections + search + inline preview) with lime accent. Chucky homelink from AIKO's block (not churnd's, which rebuilds the whole brand). Harness `src/drinks/harness.js` 7/7 (name/desc/price splice + parse + revert + saves drinks_edited.pdf). Verified visually (`scratchpad/drinks_topband.png` — edit renders on the band).

**⚠️ FONT-SUBSET LIMIT (real constraint):** Illustrator subset the font — kept the cmap but STRIPPED glyph OUTLINES for unused chars. MonospaceTypewriter (menu font) has REAL glyphs only for `,-02356` + most letters but **NO 1,4,7,8,9 and NO Q,X,q,x,z**. So a price "450" renders the 4 as BLANK ("50"). The .ai has the SAME subset (no fuller font). Fix: builder now derives `allowed` from the font's REAL glyphs (glyf `numberOfContours!=0`), not cmap — editor strips/blocks unavailable chars with the fontNote toast. price allowed=`02356`. To unlock all digits/letters: re-export the PDF from Illustrator with full font embedding (subset:off), OR embed the full MonospaceTypewriter .ttf, OR substitute a full monospace (look change). NOT done in v1.

**ADD/REMOVE + GRADIENT-FROM-DESCRIPTION shipped (2026-07-13, v2):** Reworked from the edit-only splice engine to a **band-model rebuild**. `fieldmap.json` now carries a `bands` model (8 `signature` {C0,C1,name,desc,price} + 1 `soft` {C0,C1,lines:[{name,price}]}) + `geo` constants (W280.63 H595.28 softH66.13, nameSize9/descSize7/priceSize7, nameX18/descX18.36/priceX251.99). `regenerate()` REBUILDS page-1's content stream entirely from `bands` (no more span-splicing): `buildPage()` emits, top→bottom, **strip-based gradients** (`strips()` = 90 interpolated `r g b rg x y w h re f` rects — chosen over PDF ShadingType-2 dicts: simpler, no Resources edits) + text via `txt()` (`BT 1 1 1 rg /GS0 gs /TT0 1 Tf -0.02 Tc <sz> 0 0 <sz> x y Tm (t)Tj ET`). Signature bands **auto-resize** `bh=(H-softH)/nSig` (user chose "auto-resize to fit"), name at bottom+bh*0.52 / desc −9.5 / price bottom+bh*0.46; soft band at y=0 with adaptive row spacing `gap=min(11,(softH-30)/(n-1))` baseY17. Add/remove: signature cards have a remove ✕ + a "+ Add drink" button; soft lines too (+ "+ Add soft drink"). **Gradient generator** (`gradientFor(text)`, JS port of `scratchpad/gradgen.py`): FLAVOR keyword→hex dict (mango/mint/berry/hibiscus/thai/etc.), STOP-word filter; 1 flavor → light(×1.18)→dark(×0.55), 2+ → color[0]→darkened(×0.7 last), neutral slate fallback. User chose **"Auto + tweak"**: each card has a gradient swatch + 2 native color pickers (C0/C1) + "✨ Auto from flavour" (reads name+desc). Harness `src/drinks/harness_bands.js` **14/14** (rebuild parses, add/remove counts, gradient flavor≠neutral, manual tweak in strips). **Viewer audit passed** (`scratchpad/drinks_compare.png`): rebuilt render is pixel-faithful to original (colors/text/positions), added-drink column shows a new flavor-gradient band with all 9 auto-resized.
