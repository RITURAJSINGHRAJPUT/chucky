**KEY FACTS that made this tractable:**
- Old vs new PDF: **fonts + per-page layout byte-identical** (same export tool; page0 CONTENT STREAM was md5-identical — only page1 changed). So the builder KEEPS old page-0 fields verbatim + all template metadata (`sections, icons, add_const, adv, allowed, nav_sections, jfont_by_page, page_sizes`) and rebuilds ONLY page-1 fields + recomputes page-1 section tails. For a future update where page0 also changes, drop the "page0 verbatim" shortcut and rebuild both (the parser already parses both pages; `--validate-page0` proves it reproduces them).
- The editor groups fields **purely geometrically** (`itemsForPage`: price = role price with x∈(n.x,n.x+260) & y≈n.y; desc = |x−n.x|<6 & just below; section via `nav_sections`/`sections` by col_x+y). So field **ids don't need to match the old scheme** — assign fresh `page:idx`, unique, done.
- Encoding: each name/desc/price is its own `BT … ET` block. name=`/T1_3` (AOMonoBlack) size≥12; desc=AOMonoBold (page0 `/T1_2`, page1 `/T1_0` — per `jfont_by_page`) size 6.5–7; price=`/T1_4` (AOMonoRegular) size~8 all-digits. Multi-run SAME-y = one visual line w/ multiple spans (e.g. BURRATA/HOT/HONEY → display concat NO space); different-y (Td) = separate lines (display join ' '). Byte spans include the parens `(…)`.
- Markers: dairy/gluten = `q 1 0 0 1 X Y cm\n0 0 m\n<sig>` vector blocks classified by first-path signature (dairy `-0.455 -0.011 -0.876…`, gluten `0.216 0.592 0.874…`, spicy/ghaslet starts `-0.001 0.001 l\n-0.042 0.083…`, NEW badge `-1.453 -1.683 l`); jain = a `(J)Tj` BT block. Legend icons are scale≠1 (`q s 0 0 s …`) so `q 1 0 0 1` naturally excludes them. Assign a marker to the name whose row it sits in — window `mk.x∈(n.x+4,n.x+320) & mk.y∈(n.y−rows−9, n.y+18)`; the **NEW badge rides ~14pt ABOVE the baseline** so the top of the window must be +18, not +9 (a too-tight window silently dropped 4 of 6 badges). `markerBase=[dairyX, nameY]` (icon_dairy x-offset is 0); `markers[]` ordered dairy,gluten,jain,spicy,new; `markerSpans{}` per baked marker (for removal). MARKER_TYPES = dairy,gluten,jain,spicy,new (the legend also shows a "CHILLI" icon but it's NOT a toggleable type).
- `max_chars` = per-line char capacity (roomier-text). Compute from section geometry: name `floor((price_right−col_x)/(size*0.63))`, desc `floor(divider_w/(size*0.63))`, but never below the longest baked line. **Hardcoding max_chars=12 truncated long names** (JAMUN CHEESECAKE is 16 chars → wrapName overflowed to 2 lines on a 1-line field → only "JAMUN" rendered). page1 came out name 26–28 / desc 55–57.
